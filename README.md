# Null Apex

Pusty projekt moda **Null Apex** dla Minecrafta **1.21.1** i **NeoForge**.
Na tym etapie zawiera wyłącznie konfigurację projektu i główną klasę moda.

## Wymagania

- Java 21
- Gradle Wrapper (dołączony do projektu)

## Przydatne polecenia

```bash
./gradlew build
./gradlew runClient
./gradlew runServer
```

Plik moda po zbudowaniu znajdzie się w `build/libs/`.
